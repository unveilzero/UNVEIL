## When to Use

Use when the user asks for a plain or simple explanation, asks for "STE", "STE100" or "plain technical English", or says an answer was hard to follow. Also use for step-by-step instructions where a misread step has a cost.

Do not use for creative writing, for legal or contract wording, or for text the user wants in their own voice.

This skill follows the manner of ASD-STE100 Simplified Technical English. It is not the standard and does not claim to conform to it.

## Procedure

1. Set the strength. Use the number the user gives. If the user gives none, use 80.
   - 100: apply every rule in step 2 with no exceptions.
   - 80 (default): apply every rule, with two allowances. Up to one sentence in five can run past the word limit when splitting it would hide how two ideas connect. Common everyday words are allowed without a definition.
   - 50: apply the rules for sentence length, one instruction per sentence, and active voice. Treat the rest as advice.
2. Write to these rules:
   - One idea per sentence.
   - Instructions: 20 words or fewer. Start with the action word. One action per sentence.
   - Explanations: 25 words or fewer per sentence. Six sentences or fewer per paragraph.
   - Use the active voice. Say who or what does the action.
   - Use simple tenses: present, past, future. Write "the guard stops the command", not "the command would have been stopped".
   - One word, one meaning. After you choose a word for a thing, use the same word every time. Do not switch to another word for variety.
   - Give each technical word a definition the first time it appears. Use one short sentence for the definition.
   - Use a short common word when one exists: "use", not "utilize"; "start", not "initiate"; "about", not "approximately".
   - Do not use idioms, figures of speech, or jokes that depend on wordplay.
   - Write the full form: "do not", "it is", "cannot".
   - Put a condition before the action: "If the light is red, stop."
   - Put a warning before the step it applies to, never after.
   - Use a numbered list for steps that have an order. Use a plain list for items that do not.
   - Keep numbers, names, units and commands exact. Do not round or reword them.
3. Keep all of the content. Plain wording must not remove a fact, a limit, a risk or a step. If the plain version is longer than the first version, that is correct.
4. Read the draft against the rules in step 2. Correct each sentence that breaks a rule, within the allowances of the chosen strength.
5. If the user says the result is too stiff or too loose, change the strength by 10 to 20 and write it again. Tell the user the new number.

## Pitfalls

- Making the text shorter and calling it simpler. This skill changes how something is said. It does not change how much is said.
- Removing a caution or a limit because it made a sentence long. Split the sentence. Keep the caution.
- Using two words for one thing, such as "file" in one sentence and "document" in the next. The reader will think they are two things.
- Talking down to the reader. Plain words are not childish words. Do not add praise or filler.
- Rewording a command, a file name, a figure or a quotation. Copy these exactly.
- Saying the text conforms to ASD-STE100. Conformance needs the official dictionary and a trained checker.

## Verification

- No instruction sentence is longer than 20 words, and no explanation sentence is longer than 25, outside the allowance for the chosen strength.
- Each instruction sentence starts with an action word and holds one action.
- Each technical word has a definition at first use, and each thing has one name throughout.
- Every fact, number, limit and warning in the source content is present in the result.
- Each warning stands before the step it applies to.
